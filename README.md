# A-CLI

Un bash script para ver animes sub español desde tu terminal usando mpv.

## ESTADO ACTUAL - A-CLI
* **Última actualización:** 12-02-2026
* **Versión:** 1.1
* **Compatibilidad:** Verificado y operativo al **08-10-2026**.



---

## Dependencias
1. mpv
2. curl
3. grep
4. jq

---

## Instalacion
Clone el repositorio git y conceda permisos de ejecucion a los scripts:

```bash
git clone https://github.com/IamJony/A-CLI.git
cd A-CLI
chmod +x A-CLI.sh ./modules/*
```
