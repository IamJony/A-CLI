# A-CLI

Un bash script para ver animes sub español desde tu terminal usando mpv o mplayer, compatible con FLINUX Y TINYCORE.

## ESTADO ACTUAL - A-CLI
* **Última actualización:** 31-10-2026
* **Versión:** 1.0
* **Compatibilidad:** Verificado y operativo al **31-10-2026**.



---

## Dependencias
1. mpv
2. curl
3. grep
4. jq
5. wget

## Dependencia opcional
6. yt-dlp - _solo si vas a reproducir con mplayer_

---

## Instalacion
Clone el repositorio git y conceda permisos de ejecucion a los scripts:

```bash
git clone https://github.com/IamJony/A-CLI.git
cd A-CLI
chmod +x A-CLI.sh ./modules/*
```
